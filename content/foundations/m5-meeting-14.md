This lesson uses a single handover note to practice reading: identifying structure, status labels, and what each section requires from you.

## The Sample Note

```
最優先情報：
305号室：VIPゲスト（鈴木様）。ウェルカムフルーツ対応済み。

対応中案件：
210号室：騒音クレーム。夜間スタッフ対応済み。経過確認要。

客室状況：
412号室：清掃未完了。15:00頃対応予定。

未完了タスク：
延泊希望あり（501号室）。フロント確認待ち。

特記事項：
604号室：ナッツアレルギーあり。レストランに申し送り済み。
```

## 1. Structure: What Each Line Is Made Of

Every entry follows the same pattern: **[Location] + [Situation] + [Status]**.

| Location | Situation | Status |
|---|---|---|
| <span>305号室</span> | <span>VIPゲスト（鈴木様）</span> | <span>対応済み</span> |
| <span>210号室</span> | <span>騒音クレーム</span> | <span>経過確認要</span> |
| <span>412号室</span> | <span>清掃未完了</span> | <span>15:00頃対応予定</span> |
| <span>501号室</span> | <span>延泊希望</span> | <span>確認待ち</span> |
| <span>604号室</span> | <span>ナッツアレルギー</span> | <span>申し送り済み</span> |

Every entry is traceable: you can identify where the situation is, what it is, and what has been done or still needs to happen.

## 3. What Each Section Header Signals

Each section header tells the incoming staff what kind of attention is required before reading a single entry.

| Section Header | What It Signals |
|---|---|
| <span>最優先情報</span> | Who needs elevated attention right now? |
| <span>対応中案件</span> | What is currently being handled? |
| <span>客室状況</span> | Which rooms have a non-standard status? |
| <span>未完了タスク</span> | What still requires action from the incoming shift? |
| <span>特記事項</span> | What do I need to know about a specific guest? |

## Quiz

**Looking at the sample note, which entry tells you something still requires action from the incoming shift?**

- A. 305号室：VIPゲスト（鈴木様）。ウェルカムフルーツ対応済み。
- B. 604号室：ナッツアレルギーあり。レストランに申し送り済み。
- C. 延泊希望あり（501号室）。フロント確認待ち。
- D. 210号室：騒音クレーム。夜間スタッフ対応済み。

**Correct Answer:** C

**Explanation:** 確認待ち means the task is blocked and waiting for someone else to act. The incoming staff must follow up with the front desk to resolve the extension request. Options A, B, and D all end with 済み (done/completed), meaning those tasks are closed. The 経過確認要 in option D does require a check, but among the given options, only C contains a status that explicitly signals an open, pending task with a named owner who has not yet acted.
