This lesson uses a single sample handover note to build reading skills: recognizing structure, identifying status labels, and connecting section headers to shift priorities.

## The Sample Note

The following is a complete handover note from an afternoon shift.

```
最優先情報：
305号室：VIPゲスト（鈴木様）。ウェルカムフルーツ対応済み。

対応中案件：
210号室：騒音クレーム。夜間スタッフ対応済み。経過確認要。

客室状況：
412号室：清掃未完了。15:00頃対応予定。

未完了タスク：
延泊希望あり（501号室）。フロント確認待ち。

特記事項：
604号室：ナッツアレルギーあり。レストランに申し送り済み。
```

Read it once before continuing. Note which entries feel complete and which feel like they require something from you.

## 1. Structure: What Each Line Is Made Of

Every entry in this note follows the same pattern: **[Location] + [Situation] + [Status]**.

| Entry | Location | Situation | Status |
|---|---|---|---|
| <span>305号室：VIPゲスト（鈴木様）。ウェルカムフルーツ対応済み。</span> | <span>305号室</span> | <span>VIPゲスト（鈴木様）</span> | <span>対応済み</span> |
| <span>210号室：騒音クレーム。夜間スタッフ対応済み。経過確認要。</span> | <span>210号室</span> | <span>騒音クレーム</span> | <span>経過確認要</span> |
| <span>412号室：清掃未完了。15:00頃対応予定。</span> | <span>412号室</span> | <span>清掃未完了</span> | <span>15:00頃対応予定</span> |
| <span>延泊希望あり（501号室）。フロント確認待ち。</span> | <span>501号室</span> | <span>延泊希望</span> | <span>確認待ち</span> |
| <span>604号室：ナッツアレルギーあり。レストランに申し送り済み。</span> | <span>604号室</span> | <span>ナッツアレルギー</span> | <span>申し送り済み</span> |

Every entry is traceable. You can identify where the situation is, what it is, and what has been done or still needs to happen.

## 2. Before and After

The same information written without structure looks like this.

<div class="keigo-card blue">

**Poorly written:**

```
VIPゲストがいます。
クレームがありました。
部屋がまだ準備できていません。
延泊したいお客様がいます。
アレルギーのお客様がいます。
```

**Correctly written:**

```
305号室：VIPゲスト（鈴木様）。ウェルカムフルーツ対応済み。
210号室：騒音クレーム。夜間スタッフ対応済み。経過確認要。
412号室：清掃未完了。15:00頃対応予定。
延泊希望あり（501号室）。フロント確認待ち。
604号室：ナッツアレルギーあり。レストランに申し送り済み。
```

</div>

The poorly written version is five problems with no location, no status, and no next step. The incoming staff knows something is wrong, but has no way to act on any of it.

## 3. Section Headers and the Three Questions

The section headers in this note map directly to the three questions the incoming shift must answer.

| Section Header | Question It Answers |
|---|---|
| <span>最優先情報</span> | Who needs attention right now? |
| <span>対応中案件</span> | What is currently being handled? |
| <span>未完了タスク</span> | What is unresolved? |
| <span>客室状況</span> | What else must I know? |
| <span>特記事項</span> | What else must I know? |

When writing your own notes, check whether each entry fits one of these three questions. If an entry does not fit, it is likely missing a location, a status label, or both.

## Quiz

**Looking at the sample note, which entry tells you something still requires action from the incoming shift?**

- A. 305号室：VIPゲスト（鈴木様）。ウェルカムフルーツ対応済み。
- B. 604号室：ナッツアレルギーあり。レストランに申し送り済み。
- C. 延泊希望あり（501号室）。フロント確認待ち。
- D. 210号室：騒音クレーム。夜間スタッフ対応済み。

**Correct Answer:** C

**Explanation:** 確認待ち means the task is blocked and waiting for someone else to act. The incoming staff must follow up with the front desk to resolve the extension request. Options A, B, and D all end with 済み (done/completed), meaning those tasks are closed. The 経過確認要 in option D does require a check, but among the given options, only C contains a status that explicitly signals an open, pending task with a named owner who has not yet acted.
