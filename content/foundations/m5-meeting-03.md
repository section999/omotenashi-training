This is the real operational vocabulary used in Japanese hotel systems.

## Core Operational Terms

| Japanese | English |
|---|---|
| 引き継ぎ | handover |
| 申し送り | shift note / report |
| 対応中 | currently handling |
| 対応済み | already handled |
| 未対応 | not handled yet |
| 要対応 | requires action |
| 保留 | on hold |
| 確認待ち | waiting confirmation |
| 完了 | completed |
| 依頼あり | request received |

## Quiz

**Which term means "requires action" in a hotel handover?**

- A. 対応済み
- B. 要対応
- C. 完了
- D. 保留

**Correct Answer:** B

**Explanation:** 要対応 means "requires action." 対応済み means already handled, 完了 means completed, and 保留 means on hold.
