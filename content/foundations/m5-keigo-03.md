title: 尊敬語 (Sonkeigo) in Depth
---

尊敬語 is the foundation of guest-oriented language. Its purpose is to linguistically elevate the guest's actions and existence. This lesson covers every major sonkeigo pattern used in hotel service, with the precision needed for daily application.

## The Core Rule

Use 尊敬語 whenever the **guest** is the subject of the action. It is not just about swapping verbs. It reflects the hospitality value: the guest is the honored party, and language must show that.

Before choosing a verb form, ask: **Is the guest the one doing this action?**


If yes: use 尊敬語

If no (staff is doing it): use 謙譲語

If neutral context: use 丁寧語

## Group 1: Irregular Sonkeigo Verbs

These verbs have entirely new forms in sonkeigo. They cannot be constructed by formula and must be memorized individually.

| Plain Form | Sonkeigo Form | Context |
|---|---|---|
| いる | いらっしゃいます | Guest is present |
| 来る | いらっしゃいます | Guest arrives |
| 行く | いらっしゃいます | Guest goes |
| 食べる | 召し上がります | Guest eats |
| 飲む | 召し上がります | Guest drinks |
| 言う | おっしゃいます | Guest says |
| する | なさいます | Guest does |
| 見る | ご覧になります | Guest looks / sees |
| 知る | ご存知です | Guest knows |
| くれる | くださいます | Guest gives |
| 休む | お休みになります | Guest rests |

## Group 2: Regular Sonkeigo Pattern

For verbs without special irregular forms, use:

**お + verb stem (masu-stem) + になります**

<div class="keigo-card blue">
<span class="keigo-jp"><code>お使いになります</code></span>: Guest uses<br>
<span class="keigo-jp"><code>お読みになります</code></span>: Guest reads<br>
<span class="keigo-jp"><code>お書きになります</code></span>: Guest writes<br>
<span class="keigo-jp"><code>お待ちになります</code></span>: Guest waits<br>
<span class="keigo-jp"><code>お持ちになります</code></span>: Guest carries / has
</div>

Construction: お + [verb masu-stem] + になります. For example: 書きます → お書きになります, 待ちます → お待ちになります.

## Group 3: ご + Sino-Japanese Verb Stems

For Chinese-origin (漢語) verb stems, use ご instead of お:

<div class="keigo-card blue">
<span class="keigo-jp"><code>ご利用になります</code></span>: Guest uses a service<br>
<span class="keigo-jp"><code>ご確認になります</code></span>: Guest confirms<br>
<span class="keigo-jp"><code>ご予約なさいます</code></span>: Guest makes a reservation<br>
<span class="keigo-jp"><code>ご到着になります</code></span>: Guest arrives<br>
<span class="keigo-jp"><code>ご滞在になります</code></span>: Guest stays
</div>

## Critical Error: Sonkeigo Applied to Staff

A serious mistake is using sonkeigo to describe the staff's own actions. These verbs apply only to guests.

<div class="keigo-card blue">
<strong>Wrong:</strong> <span class="keigo-jp"><code>私がいらっしゃいます。</code></span><br>
<strong>Correct:</strong> <span class="keigo-jp"><code>私がおります。</code></span><br><br>
<strong>Wrong:</strong> <span class="keigo-jp"><code>担当者がいらっしゃいます。</code></span><br>
<strong>Correct:</strong> <span class="keigo-jp"><code>担当者がおります。</code></span>
</div>

いらっしゃいます is an honorific form. Applying it to yourself or a colleague elevates them above the guest, which reverses the hospitality relationship. おります is the humble (謙譲語) form of いる and is correct for staff use.

## Sonkeigo Question Forms

<div class="keigo-card blue">
<span class="keigo-jp"><code>〜でいらっしゃいますか</code></span><br>
Are you 〜?<br>
Example: <span class="keigo-jp"><code>田中様でいらっしゃいますか。</code></span><br><br>
<span class="keigo-jp"><code>〜はいかがでしょうか</code></span><br>
Would you like 〜?<br>
Example: <span class="keigo-jp"><code>お飲み物はいかがでしょうか。</code></span><br><br>
<span class="keigo-jp"><code>なさいますか</code></span><br>
Will you do 〜?<br>
Example: <span class="keigo-jp"><code>朝食はいかがなさいますか。</code></span>
</div>

## Quiz

**A staff member wants to ask "Will you be checking in?" Which is correct?**

- A. 「チェックインしますか？」
- B. 「チェックインいたしますか？」
- C. 「チェックインなさいますか？」
- D. 「チェックインされていますか？」

**Correct Answer:** C

**Explanation:** The guest is performing the check-in action, so 尊敬語 is required. なさいます is the sonkeigo form of する, making option C correct. Option A uses plain language. Option B uses いたす, which is 謙譲語 and implies the staff is checking in. Option D is grammatically awkward and not standard hotel keigo. The guest's actions always require the honorific form.
